# Gamja Bot · 개발 프리뷰

사용자와 여러 AI 에이전트가 같은 대화방에서 함께 논의하고 작업하는 데스크톱 프로그램입니다. CLI와 앱은 같은 코어를 사용하며, 하나의 에이전트를 여러 대화방에 배치할 수 있습니다.

이 저장소에는 설치파일과 설치 안내를 공개합니다. 제품 소스 저장소는 별도로 관리합니다.

## Mac Apple Silicon

[최신 프리뷰 P](https://github.com/sanghyun-io/gamja-bot-releases/releases/tag/v1.0.0-mac-arm64-preview.20261011-p)와 [설치 안내](INSTALL.md)를 확인하세요. 유료 Developer ID 서명·공증·공식 스토어 배포는 적용하지 않았습니다.

P는 앱 세션 처리와 안내 문구를 수정했습니다. 관련 소스 테스트 42개, 독립 리뷰, 현재 Mac mini의 교체 설치 후 CLI 자동 로그인·기존 데이터 보존·정상 가동을 확인했습니다. 설치된 P 앱에서도 자동 로그인, OpenCode Go 무료 모델 연결 테스트, 두 에이전트의 2라운드 대화와 동료 의견 반영, 최종 결과 정리까지 확인했습니다. 실제 세션 만료 후 복구, 별도 Mac 설치, 두 적격 제공자와 사용자 업무 가치 검증은 남아 있습니다. 모델 답변에는 잘못된 기술 설명이 있어 답변 품질 검증도 계속합니다.

이 저장소는 설치 파일 배포용입니다. 프로그램 소스 저장소는 비공개로 유지합니다. 이전 릴리즈는 해당 날짜와 버전의 검증 결과로 구분해 보존합니다.

이 설치 파일은 Mac Apple Silicon(ARM64) 전용이며 Intel Mac에 설치할 수 없습니다. Windows 실행은 현재 네이티브 검증 범위에 포함하지 않습니다. 이전 Windows 파일은 기존 릴리즈에서 확인할 수 있습니다.

## 피드백

OS·앱 버전·발생 단계와 민감정보를 지운 오류 문구를 남겨 주세요. API 키·비밀번호·개인 대화·자동 로그인 자료는 올리지 마세요. 계정과 로컬 데이터는 설치파일에 포함되지 않습니다.
