# Gamja Bot · 개발 프리뷰

사용자와 여러 AI 에이전트가 같은 대화방에서 함께 논의하고 작업하는 데스크톱 프로그램입니다. CLI와 앱은 같은 코어를 사용하며, 하나의 에이전트를 여러 대화방에 배치할 수 있습니다.

이 저장소에는 설치파일과 설치 안내를 공개합니다. 제품 소스 저장소는 별도로 관리합니다.

## Mac Apple Silicon

[최신 프리뷰 S](https://github.com/sanghyun-io/gamja-bot-releases/releases/tag/v1.0.0-mac-arm64-preview.20261011-s)와 [설치 안내](INSTALL.md)를 확인하세요. 유료 Developer ID 서명·공증·공식 스토어 배포는 적용하지 않았습니다.

S는 최종 답변이 원래 논의의 실패나 누락을 숨기지 않도록 보완했습니다. 원본 논의가 부분 결과이면 짧은 안내와 원본 확인 버튼을 표시합니다. 이후의 별도 재시도 성공으로 원래 실패 기록을 바꾸지 않습니다. 관련 백엔드 42개·프론트엔드 108개 소스 검사와 독립 리뷰를 통과했고, 현재 Mac mini에 같은 설치파일을 교체해 CLI·앱 자동 로그인, 원본 논의의 결과 4개·실패 1개 표시와 기존 데이터 보존을 확인했습니다.

새 설치본에서 두 제공자를 다시 호출한 검증은 이번 업데이트에 포함하지 않았습니다. 이전 R의 실제 협업·방별 문맥 검증은 해당 버전의 근거로 유지합니다. 별도 Mac의 첫 설치와 실제 사용자의 업무 가치·답변 품질 검증은 남아 있습니다. 모바일 기기 연결과 대화 동기화는 아직 제공하지 않습니다.

이 저장소는 설치 파일 배포용입니다. 프로그램 소스 저장소는 비공개로 유지합니다. 이전 릴리즈는 해당 날짜와 버전의 검증 결과로 구분해 보존합니다.

이 설치 파일은 Mac Apple Silicon(ARM64) 전용이며 Intel Mac에 설치할 수 없습니다. Windows 실행은 현재 네이티브 검증 범위에 포함하지 않습니다. 이전 Windows 파일은 기존 릴리즈에서 확인할 수 있습니다.

## 피드백

OS·앱 버전·발생 단계와 민감정보를 지운 오류 문구를 남겨 주세요. API 키·비밀번호·개인 대화·자동 로그인 자료는 올리지 마세요. 계정과 로컬 데이터는 설치파일에 포함되지 않습니다.
