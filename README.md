# Gamja Bot · Mac ARM 개발자 프리뷰

사용자와 여러 AI 에이전트가 같은 대화방에서 논의하고 작업하는 데스크톱 프로그램입니다. CLI가 코어이며 앱은 같은 코어의 UI입니다. 같은 Agent를 여러 대화방에 배치하고, 각 방의 대화를 분리해 진행할 수 있습니다.

이 저장소에는 설치파일과 설치 안내를 공개합니다. 제품 소스는 비공개로 관리합니다.

## Mac Apple Silicon

[프리뷰 AA1](https://github.com/sanghyun-io/gamja-bot-releases/releases/tag/v1.0.0-mac-arm64-preview.20261013-aa1)과 [설치 안내](INSTALL.md)를 확인하세요. Apple Developer ID·공증·공식 스토어 배포는 적용하지 않았습니다.

이번 프리뷰는 모델 설정 오류를 고친 뒤에도 재시도가 막히던 문제를 수정합니다. 원래 실패 기록을 수정하지 않고 안전하게 새 요청으로 이어갑니다. 기존 계정·연결·Agent 설정·대화·이미지는 보존합니다.

동일한 최종 설치본에서 CLI·GUI 저장 로그인, Alibaba Coding Plan 연결·모델 테스트, 다중 Agent 협업과 요청 결과 정리, 캡처·썸네일·확대 보기, 실패 후 재시도를 확인했습니다. 구체적인 검증 범위와 남은 한계는 릴리즈 노트에 기록합니다.

실제 사용자 파일럿, solo/team 비교와 깨끗한 OS 첫 설치는 후속 검증입니다. 개발자 프리뷰 마감을 전체 제품 품질 검증 완료로 보지 않습니다. 원격 오류 보고 수신은 별도 확인 중입니다. 모바일 연결과 기기 간 동기화는 아직 제공하지 않습니다.

이 설치파일은 Apple Silicon ARM64 전용입니다. Intel Mac·Windows의 이번 버전 실행은 검증하지 않았습니다. 이전 설치파일은 과거 릴리즈에서 확인할 수 있습니다.

## 피드백

OS·앱 버전·발생 단계와 민감정보를 지운 오류 문구를 남겨 주세요. API 키·비밀번호·개인 대화·자동 로그인 자료를 공개 이슈에 올리지 마세요. 계정과 로컬 데이터는 설치파일에 포함하지 않습니다.
