# Gamja Bot · 개발 프리뷰

사용자와 여러 AI 에이전트가 같은 대화방에서 논의하고 작업하는 데스크톱 프로그램입니다. CLI와 앱은 같은 코어를 사용하며, 하나의 에이전트를 여러 대화방에 배치할 수 있습니다.

이 저장소는 설치파일과 설치 안내를 공개하는 곳입니다. 제품 소스는 별도로 비공개 관리합니다.

## Mac Apple Silicon

[최신 프리뷰 U2](https://github.com/sanghyun-io/gamja-bot-releases/releases/tag/v1.0.0-mac-arm64-preview.20261012-u2)와 [설치 안내](INSTALL.md)를 확인하세요. Apple Developer ID 서명·공증·공식 스토어 배포는 적용하지 않았습니다.

U2는 대화 결과를 정리할 때 실제 동료 발언과 실패 기록을 구분하도록 개선했습니다. 현재 Mac에서 실제 교체 설치했고 기존 계정·연결·대화 데이터 보존, CLI 자동 로그인과 정상 가동을 확인했습니다. 같은 설치본의 CLI에서 Alibaba Coding Plan의 qwen3.7-plus 및 OpenCode Go의 longcat-2.5-preview-free text 연결 테스트가 각각 성공했습니다.

부분 결과의 최종 정리 한 표본에서 새 응답이 실제 발언과 기록된 실패를 구분했고, 같은 요청을 다시 조회해도 결과가 중복 생성되지 않았습니다. 원래 대화와 실패 기록은 보존됐습니다. 이는 모든 모델의 답변 정확성이나 실제 업무 가치를 보장하지 않습니다.

U2 앱 화면의 전체 사용자 흐름과 새 환경에서의 첫 설치·실제 사용자 평가는 아직 검증 중입니다. 이전 T의 화면·여러 방 동시 대화 검증은 당시 버전의 근거입니다. 모바일 연결과 기기 간 대화 동기화는 아직 제공하지 않습니다.

이 설치파일은 Apple Silicon(ARM64) 전용입니다. Intel Mac에 설치할 수 없습니다. 현재 U2 Windows 설치파일은 없으며 이전 Windows 파일은 과거 릴리즈에서 확인할 수 있습니다. 이전 릴리즈와 설치파일은 보존합니다.

## 피드백

OS·앱 버전·발생 단계와 민감정보를 지운 오류 문구를 남겨 주세요. API 키·비밀번호·개인 대화·자동 로그인 자료는 올리지 마세요. 계정과 로컬 데이터는 설치파일에 포함하지 않습니다.
