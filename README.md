# Gamja Bot · 개발 프리뷰

사용자와 여러 AI 에이전트가 같은 대화방에서 함께 논의하고 작업하는 데스크톱 프로그램입니다. CLI와 앱은 같은 코어를 사용하며, 하나의 에이전트를 여러 대화방에 배치할 수 있습니다.

이 저장소는 설치파일과 설치 안내를 공개하는 배포 저장소입니다. 제품 소스 저장소는 별도로 관리합니다.

## 다운로드

[최신 Mac Apple Silicon 프리뷰](https://github.com/sanghyun-io/gamja-bot-releases/releases/tag/v1.0.0-mac-arm64-preview.20261011-n)

현재 제공 파일은 **Mac Apple Silicon(ARM64)** 용입니다. Intel Mac에 설치할 수 없습니다. 현재 후보의 Windows 실행은 검증하지 않았으며, 이전 Windows 후보를 최신 버전으로 재배포하지 않습니다.

[설치 안내](INSTALL.md)를 먼저 확인하세요. 이 버전은 공식 스토어 등록·Apple 공증을 받지 않은 개발 프리뷰여서 첫 실행 때 macOS 경고가 표시될 수 있습니다.

## 현재 프리뷰 범위

이번 N 프리뷰는 자격증명 복구 데이터를 기존 고정 브로커로 전달할 때 발생한 호환 문제를 수정했습니다. 두 역할 팀의 기본 대화 지침과 같은 요청의 후속 논의 흐름을 유지합니다. 모델이 매번 지침을 따르는지는 별도 품질 검증 대상입니다.

Mac ARM의 실제 교체 설치, 기존 계정·데이터 보존과 CLI 자동 로그인은 확인 후 이 릴리즈를 제공합니다. 같은 N 코어에서 새 계정 가입·자동 로그인 복원, 연결 오류 후 키 수정·모델 테스트·같은 요청 재시도, 두 에이전트의 팀 대화와 연결 해제를 실제 CLI로 확인했습니다. 같은 후보의 GUI 전체 흐름, 별도 새 Mac의 설치, 실제 사용자의 첫 사용 및 협업 품질 평가는 진행 중입니다. 이전 프리뷰에서 확인한 여러 방 동시 실행·문맥 격리 결과를 이 후보의 새 실측으로 표시하지 않습니다.

모든 제공자·모델의 응답이나 상품 한도를 보장하지 않습니다. 기존의 사용자 Agent 지침을 이 프리뷰의 새 기본값으로 덮어쓰지 않습니다.

## 피드백

문제를 보고할 때 OS·앱 버전·발생 단계와 민감정보를 지운 오류 문구를 남겨 주세요. API 키·비밀번호·개인 대화·자동 로그인 자료는 올리지 마세요. 계정과 로컬 데이터는 설치파일에 포함되지 않습니다.
