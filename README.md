# Gamja Bot · 개발 프리뷰

사용자와 여러 AI 에이전트가 같은 대화방에서 함께 논의하고 작업하는 데스크톱 프로그램입니다. CLI와 앱은 같은 코어를 사용하며, 하나의 에이전트를 여러 대화방에 배치할 수 있습니다.

이 저장소에는 설치파일과 설치 안내를 공개합니다. 제품 소스 저장소는 별도로 관리합니다.

## 다운로드

[최신 Mac Apple Silicon 프리뷰 O](https://github.com/sanghyun-io/gamja-bot-releases/releases/tag/v1.0.0-mac-arm64-preview.20261011-o)

현재 파일은 **Mac Apple Silicon(ARM64)** 용입니다. Intel Mac에 설치할 수 없습니다. 이 후보의 Windows 실행은 검증하지 않았습니다.

[설치 안내](INSTALL.md)를 먼저 확인하세요. 공식 스토어 등록·Apple Developer ID·공증은 적용하지 않은 개발 프리뷰여서 첫 실행 때 macOS 경고가 표시될 수 있습니다. 앱별 수동 실행 안내를 제공합니다.

## 이번 변경과 확인 범위

O는 CLI 오류 조회가 선택한 프로필의 기록을 읽도록 수정했습니다. 실제 O CLI에서 두 임시 프로필의 오류 조회 격리를 확인했습니다. 테스트용 오류 기록을 사용했으며 LLM 요청은 발생하지 않았습니다.

현재 Mac mini에서 실제 교체 설치 후 같은 사용자 자동 로그인과 기존 32개 테이블의 데이터·연결 참조 보존을 확인했습니다. 같은 O의 GUI 전체 흐름, 별도 새 Mac의 설치, 실제 사용자의 첫 사용 및 협업 품질 평가는 아직 검증 중입니다.

이전 N에서는 실제 여러 제공자의 팀 대화, 서로의 발언 반영, 같은 에이전트의 세 대화방 동시 실행과 문맥 격리, 결과 정리와 재조회가 확인됐습니다. 이를 O의 새 모델 실행으로 표시하지 않습니다. 모든 제공자·모델의 응답이나 상품 한도를 보장하지 않습니다.

## 피드백

OS·앱 버전·발생 단계와 민감정보를 지운 오류 문구를 남겨 주세요. API 키·비밀번호·개인 대화·자동 로그인 자료는 올리지 마세요. 계정과 로컬 데이터는 설치파일에 포함되지 않습니다.
