# Gamja Bot · 개발 프리뷰

사용자와 여러 AI 에이전트가 같은 대화방에서 함께 논의하고 작업하는 데스크톱 프로그램입니다. CLI와 앱은 같은 코어를 사용하며, 하나의 에이전트를 여러 대화방에 배치할 수 있습니다.

이 저장소에는 설치파일과 설치 안내를 공개합니다. 제품 소스 저장소는 별도로 관리합니다.

## Mac Apple Silicon

[최신 프리뷰 T](https://github.com/sanghyun-io/gamja-bot-releases/releases/tag/v1.0.0-mac-arm64-preview.20261012-t)와 [설치 안내](INSTALL.md)를 확인하세요. 유료 Developer ID 서명·공증·공식 스토어 배포는 적용하지 않았습니다.

T는 저장된 로그인에 접근할 수 없을 때 다시 시도하거나 문제를 신고할 수 있도록 안내를 개선했습니다. 현재 Mac mini에서 교체 설치 후 기존 계정·연결·대화 보존과 CLI·앱 자동 로그인을 확인했습니다. 같은 앱에서 Alibaba와 OpenCode Go 무료 모델의 text 연결 테스트를 각각 한 번 실행해 실제 응답에 성공했습니다. 별도 대화 검증에서는 한 에이전트의 세 방 동시 활동과 같은 방 동료의 발언 반영도 확인했습니다.

협업 표본의 응답 한 건은 시간 초과됐고, 해당 에이전트만 재시도해 성공했습니다. 원래 요청의 부분 결과와 실패 기록은 그대로 보존합니다. 최종 정리는 원본에 연결되지만 모델 문장의 정확성과 업무 가치를 보장하지 않습니다. 별도 Mac의 첫 설치와 실제 사용자의 평가가 남아 있습니다. 모바일 기기 연결과 대화 동기화는 아직 제공하지 않습니다.

이 저장소는 설치 파일 배포용입니다. 프로그램 소스 저장소는 비공개로 유지합니다. 이전 릴리즈는 해당 날짜와 버전의 검증 결과로 구분해 보존합니다.

이 설치 파일은 Mac Apple Silicon(ARM64) 전용이며 Intel Mac에 설치할 수 없습니다. Windows 실행은 현재 네이티브 검증 범위에 포함하지 않습니다. 이전 Windows 파일은 기존 릴리즈에서 확인할 수 있습니다.

## 피드백

OS·앱 버전·발생 단계와 민감정보를 지운 오류 문구를 남겨 주세요. API 키·비밀번호·개인 대화·자동 로그인 자료는 올리지 마세요. 계정과 로컬 데이터는 설치파일에 포함되지 않습니다.
